# Programa para somar números

## Guia como utilizar

### Requisitos
- Ambiente linux com terminal bash e compilador gcc instalado

### Como rodar o programa
- Com o projeto localmente, abra o diretório do projeto no terminal e navegue até a pasta do código com `cd src`
- Estando na pasta src, compile o programa com `gcc main.c -o somador`, isso criará o binário executável do programa
- Para rodar, digite `./somador`.
